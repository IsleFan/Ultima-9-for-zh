創世紀 IX：羽化昇天　繁體中文版

Mac 安裝包 @VERSION@ · 中文化 @VERSION@ · Wine 10（Sikarugir 開源版）

這個版本

  • 內含原作者發佈的正式版中文化 @VERSION@，未修改。影片中文字幕在 Mac 上可以正常顯示（預設開啟）。
  • Mac 安裝包只是把中文化、Wine 執行環境與安裝程式打包在一起；中文化本身的說明見 runtime/U9CHT/說明.txt。
本安裝包不含遊戲。請自備正版 Ultima IX: Ascension（GOG 版或 Steam 版，遊戲版本 1.19f）。 中文化目前是內部測試版，譯文為初稿。

二、第一次打開前：解除 Mac 安全限制

從網路下載的程式沒有經過 Apple 公證，第一次雙擊時 macOS 會擋下來。請用下面其中一種方法：

方法 A：用「終端機」一次解除（推薦）

  1. 打開「應用程式 → 工具程式 → 終端機」。
  2. 輸入下面這段文字，最後空一格（先不要按 Return）： 
    xattr -dr com.apple.quarantine
  3. 把整個 U9CHT-@VERSION@-macOS 資料夾從 Finder 拖進終端機視窗，路徑會自動填上。
  4. 按 Return。沒有任何訊息就代表成功。

方法 B：用系統設定放行

  1. 雙擊 1_安裝.command，出現「無法打開」的警告時按「完成」或「好」。
  2. 打開「系統設定 → 隱私權與安全性」，捲到最下方，在「已阻擋 1_安裝.command」旁按「仍要打開」，輸入密碼後再按一次「打開」。
  3. 安裝程式啟動後會自動解除整個資料夾的限制，之後就不用再做。

三、安裝

  1. 把 U9CHT-@VERSION@-macOS 資料夾放到你想放的地方，例如「文件」或「遊戲」資料夾。
    安裝後遊戲和存檔都會放在這個資料夾裡，之後請不要再搬動或改名（要搬就整個資料夾一起搬）。
  2. 雙擊 1_安裝.command。會開一個終端機視窗顯示進度。
  3. 選擇遊戲來源：
    • 「GOG 安裝檔」→ 選 setup_ultima_ix_….exe
    • 「遊戲資料夾」→ 選有 u9.exe 的資料夾
  4. 等待約 2～5 分鐘（含下載 Wine 引擎，視網路速度而定），看到「安裝完成」就好了。原本的安裝檔或遊戲資料夾不會被修改。

重新執行 1_安裝.command 可以重新安裝；既有存檔會自動備份並還原，已下載過的 Wine 引擎不會重新下載。

關於 Wine 引擎的下載

為了縮小安裝包，Wine 引擎沒有附在裡面。安裝程式會依下面的順序處理：

  1. 已經安裝過引擎 → 直接使用。
  2. 找到已下載的檔案 WS12WineSikarugir10.0_8.tar.xz（放在本資料夾、runtime 資料夾或「下載項目」）→ 驗證檢查碼後直接使用，不需要網路。
  3. 都沒有 → 自動從網路下載（約 166 MB），驗證檢查碼後安裝。

沒有網路或自動下載失敗時：在可以上網的地方用瀏覽器下載下面這個檔案，放進 U9CHT-@VERSION@-macOS 資料夾（或「下載項目」），再執行 1_安裝.command：

https://github.com/Sikarugir-App/Engines/releases/download/v1.0/WS12WineSikarugir10.0_8.tar.xz

SHA-256：2a6bcf2a3bf13cddf825599b6bc1e3659cbf71e1282c6d77141a92f6ac8d4c68。檢查碼不符的檔案不會被使用。

四、開始遊戲

  1. 雙擊 2_啟動 U9 中文版.command。
  2. 有接多個螢幕時，會先問你要在哪個螢幕玩（見下一節）。
  3. 中文化首頁出現後，按「開始遊戲」。第一次會先產生中文化資料，請稍等。
  4. 遊戲期間會留著一個終端機視窗，請不要關掉。玩完關掉首頁後，終端機顯示「已結束」才可以關。
首頁的「視窗化」在 Mac 上沒有作用：勾了仍是全螢幕，用預設即可。
首頁的其他功能（字型、字距、滑鼠滾輪翻頁、敵人血條、按鍵設定等）都可以照常使用，說明見 runtime/U9CHT/說明.txt。

多螢幕

  • Wine 只會把遊戲開在 macOS 的「主要顯示器」上，所以啟動時選的螢幕會暫時被設成主要顯示器。
  • 一離開遊戲就會自動還原成原本的螢幕排列。在首頁再按一次「開始遊戲」的話，會開在原本的主螢幕；要換螢幕請關掉首頁、重新雙擊啟動。
  • 萬一程式異常中斷、螢幕排列沒有還原，下次啟動時會先自動還原。

首頁太大

首頁會依螢幕高度自動縮小（例如 MacBook 內建螢幕），所以字可能小一點，這是正常的。

五、已知問題

關於穩定性與 Wine 版本

WineHQ 官方的 Wine 10／11 在 Apple Silicon 上執行 32 位元遊戲時會隨機當機（WineHQ bug 60494，Rosetta 相關，官方沒有修正計畫）。 本安裝包因此改用開源專案 Sikarugir 編譯的 Wine 10.0（安裝時自動下載），在製作者的 Mac（Apple Silicon、macOS 27）上測試不再出現這個當機。

這個 Wine 是免費的。Wine 是依 LGPL 授權的開放原始碼軟體，Sikarugir 是社群維護的開源專案， 可以免費使用與散布，不需要購買 CrossOver 或任何其他商業軟體。它與 CodeWeavers（CrossOver）、WineHQ 官方都沒有關係，也不受其支援。

即使如此，仍建議常按 Ctrl+S 存檔。若跳出 Wine 錯誤視窗，關掉它、回到首頁再按「開始遊戲」即可。

  • 已經有進行中的遊戲時，啟動會直接回到上次的場景，不會再播 ORIGIN 標頭與開場影片。
  • Intel Mac：尚未實際測試。
  • 「視窗化」無效：勾選後遊戲仍會佔滿整個螢幕。
  • 原版遊戲本身的問題（中文化說明也有提到）：讀取存檔後再「開新遊戲」世界不會重置，要開新遊戲請先完全離開再重新進入。
  • 全螢幕時理論上可以用 ⌘+Tab 切到其他程式，但尚未確認切回來是否正常，切換前請先存檔。

七、移除

先把 savegame 資料夾備份出來（如果還想保留存檔），再把整個 U9CHT-@VERSION@-macOS 資料夾丟到垃圾桶即可。本安裝包不會在其他地方留下檔案。

八、疑難排解

狀況處理方式
雙擊 .command 顯示「無法打開」依第二節解除安全限制。
安裝時「下載 Wine 引擎失敗」確認網路連線後重新執行；或依第三節手動下載後再安裝。
安裝時「解開安裝檔失敗」確認 .exe 和 .bin 在同一個資料夾，而且檔案完整下載（可在 GOG 網站重新下載）。
首頁顯示找不到遊戲或版本不符按「自動搜尋」，或「選擇資料夾」指到 C:\GOG Games\Ultima 9。必須是 1.19f 版。
首頁顯示「ddraw.dll 不是 GOG 版附的版本」遊戲資料夾裡的 ddraw.dll 被改過。請重新執行 1_安裝.command。
螢幕排列沒有還原重新雙擊啟動（會先自動還原），或到「系統設定 → 顯示器」手動調整。
回報問題首頁「回報問題」按鈕。請附上 prefix/drive_c/U9CHT/logs/ 裡最新的記錄檔與 logs/wine-last.log。
