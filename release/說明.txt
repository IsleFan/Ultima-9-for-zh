創世紀 IX：羽化昇天　繁體中文版（內部測試版）
================================================

這是 Ultima IX: Ascension 的非官方繁體中文化。目前是內部測試版：
譯文全部是初稿，還沒有人工校對；畫面與功能也還在測試中。
看到錯字、翻譯不通順、文字超出框、當機，都歡迎回報（見最後一節）。


一、需要什麼
------------
- Windows 10 或 11。
- 正版 Ultima IX: Ascension，GOG 版或 Steam 版都可以（遊戲版本 1.19f）。
  這個中文化不含任何遊戲檔案，一定要先裝好遊戲。
- 遊戲本身請先能正常執行一次（建議用遊戲內附的設定程式設定好畫面）。


二、安裝
--------
1. 把整個資料夾解壓縮到任何地方，例如「文件」底下。
   不需要、也不建議放進遊戲資料夾。
   資料夾路徑請不要放在需要系統管理員權限的地方（例如 Program Files 資料夾）。
2. 執行資料夾裡的 U9Cht.exe（中文化首頁）。
3. 首頁會自動尋找遊戲。找不到時，按「選擇資料夾」指到有 u9.exe 的資料夾。
4. 按「開始遊戲」。

第一次按「開始遊戲」時，程式會讀取你自己的遊戲檔，產生中文化資料
（放在本資料夾的 data\static）。之後就不必再產生。


三、每次遊玩
------------
- 一律從 U9Cht.exe 的「開始遊戲」進入，不要直接執行 u9.exe。
- 開始遊戲時，首頁把中文檔放進遊戲資料夾；離開遊戲後自動換回原本的檔案。
  所以直接執行 u9.exe 會是原本的英文版。
- 離開遊戲請用遊戲內的選單（Esc 開日誌目錄 →「離開遊戲」，或 Ctrl+X）。
- 存檔與英文版共用，互相可以讀取。
  存檔位置和原版一樣，在遊戲資料夾的 savegame 子資料夾（u9game1.sav 等）。
  本資料夾裡沒有存檔，刪掉它不影響存檔。
- 用中文化寫下的日誌筆記，改用英文版開同一份進度時可能顯示成亂碼（存檔不受影響）。

雲端存檔（GOG Galaxy）：
- 直接執行 U9Cht.exe 時，Galaxy 不知道你在玩，不會同步雲端存檔。
- 要同步，請讓 Galaxy 改用中文化啟動：在 Galaxy 的 Ultima IX 頁面，
  按「開始遊戲」旁的設定圖示 →「管理安裝」→「設定」，
  勾選自訂執行檔，指到本資料夾的 U9Cht.exe。
  之後從 Galaxy 按「開始遊戲」會打開中文化首頁，關閉首頁時 Galaxy 會同步。
- Steam 版是否支援雲端存檔尚未確認。


四、首頁的設定
--------------
強化功能（都可以在首頁勾選開關）：
- 游標停留顯示名稱：滑鼠停在物品上就顯示名稱，不必按住 X。
- 滾輪翻頁：日誌、法術書、書本可以用滑鼠滾輪翻頁。
- Ctrl＋滾輪縮放鏡頭。
- 影片中文字幕。
- 體力／法力數值：在畫面下方兩條橫條上顯示數字。
- 傷害／法力飄字。
- 敵人血條：鎖定或攻擊中的敵人顯示在畫面上方。
- 跳躍鍵自動攀爬：前面有能爬的地方就攀爬（預設關閉）。
- 點擊任意處跳過對白：對話時點畫面任何地方就跳到下一句。
- Esc 開啟日誌目錄：沒有開著的書或視窗時，按 Esc 直接翻到日誌目錄。

畫面與字型：
- 字型：預設使用附帶的「jf open 粉圓」，也可以選自己的字型。
- 日誌、對話的字距與行距。
- 解析度：800×600、1024×768、1280×960、1600×1200（只支援 4:3）。
- 視窗化：勾選後以視窗模式執行。

按鍵設定：
- 首頁的「按鍵設定」可以改所有遊戲按鍵。
- 遊戲中按 Ctrl+Shift+K 也能叫出這一頁，改完儲存後回到遊戲約一秒內生效。
- 作弊頁是遊戲內建的開發用作弊，另外有中文化加的「金幣增加一千」
  （身上要先有金幣）。標 ⚠ 的三項據報會把背包重置，使用前請先存檔。


五、常用按鍵（遊戲預設）
------------------------
  方向鍵       移動            空白鍵    跳躍
  C            攀爬            B         背包
  J            日誌（回到上次那頁）
  Esc          日誌目錄（中文化功能）
  Ctrl+Z       狀態頁（屬性、金幣、箭、技能）
  Ctrl+S／Ctrl+L  存檔／讀檔    Ctrl+M    世界地圖
  S            法術書          Tab       進入／離開戰鬥
  T            鎖定目標        Enter     對話時跳下一句
  數字鍵 1～N  對話時直接選選項


六、已知的問題
--------------
以下是英文原版本來就有的問題：
- 讀取存檔後再「開新遊戲」，世界不會重置。要開新遊戲請先完全離開遊戲再重新開始。
- 原版在全螢幕時切換視窗（Alt+Tab）或截圖，可能出現
  「Unable to create Primary Surface in Video Memory!」後結束。
  要截圖請先在首頁勾「視窗化」。

中文化本身：
- 對話選項之間的距離不受「對話行距」影響。
- 少數較長的對白會換成三行以上。
- 防毒軟體可能誤判。中文化用一個名為 dsound.dll 的小程式，
  只在遊戲執行期間放進遊戲資料夾，離開遊戲後就移除。
  若被攔截，請把本資料夾加入防毒軟體的排除清單。


七、移除
--------
- 中文化不會永久修改遊戲：每次離開遊戲都已換回原本的檔案。
- 直接刪除本資料夾即可。
- 例外：如果你在「按鍵設定」存過按鍵，遊戲資料夾裡會多一個 U9CHT.kmp，
  遊戲的 Options.ini 也會指向它。要恢復原本按鍵，在按鍵設定按「載入原版預設」後儲存，
  或把 Options.ini 的 Current_Keymap 改回 Default.kmp。
- 首頁選過的解析度會留在遊戲設定裡，和在遊戲內改解析度一樣。


八、回報問題
------------
- 首頁的「回報問題」按鈕會打開 GitHub Issues。
- 請盡量附上：發生在哪裡（地點、和誰對話）、畫面截圖、
  以及本資料夾 logs 裡最新的紀錄檔。
